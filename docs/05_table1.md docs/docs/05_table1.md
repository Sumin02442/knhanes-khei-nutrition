# 5주차 팀 과제: Table 1 작성 및 분석 (8팀 - 읍면 거주)

## B-1. 배정받은 노출 변수의 건강 관련성
본 연구에서는 거주지 특성인 '읍면 지역 거주(urban == 2)'를 주요 노출 변수로 설정하였다. 읍면 지역 거주는 동 지역(도시)에 비해 의료 접근성 부족, 인구 고령화, 보건 인프라의 차이 등으로 인해 만성질환 관리율이 낮고 전반적인 건강 위험을 높일 것으로 예상된다. 특히 읍면 거주 여부는 국민건강영양조사 표본 설계 시 조사구(PSU) 단위로 분류되는 특성이 있어, 연령·소득·교육 수준 등 다양한 인구사회학적 요인과 복합적으로 결합하여 건강 결과에 영향을 미칠 수 있다.
