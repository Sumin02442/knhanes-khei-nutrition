# 5주차 팀 과제: Table 1 작성 및 분석 (8팀 - 읍면 거주)

## B-1. 배정받은 노출 변수의 건강 관련성
본 연구에서는 거주지 특성인 '읍면 지역 거주(urban == 2)'를 주요 노출 변수로 설정하였다. 읍면 지역 거주는 동 지역(도시)에 비해 의료 접근성 부족, 인구 고령화, 보건 인프라의 차이 등으로 인해 만성질환 관리율이 낮고 전반적인 건강 위험을 높일 것으로 예상된다. 특히 읍면 거주 여부는 국민건강영양조사 표본 설계 시 조사구(PSU) 단위로 분류되는 특성이 있어, 연령·소득·교육 수준 등 다양한 인구사회학적 요인과 복합적으로 결합하여 건강 결과에 영향을 미칠 수 있다.

1. **읍면 거주 비율 (`urban`)**:
   - 국민건강영양조사 표본 설계 특성상 조사구(PSU) 단위 추출로 인해 비가중 비율과 실제 행정구역 인구 비율 간 차이가 크게 존재한다. 가중치(추출률 및 동의율 보정) 적용 시 모집단 거주 분포에 맞게 수치가 조정된다.
2. **연령 (`age`)**:
   - 읍면 지역은 동 지역에 비해 인구 고령화 비율이 높다. 거주지 단위의 추출 가중치가 적용되면서 전체 모집단의 연령 분포 추정치에 영향이 미쳐 가중 전후 평균/분포 차이가 크게 나타난다.
3. **교육 수준 (`edu`)**:
   - 거주 지역별 산업 및 인구 구조 특성이 연령 및 소득 구조와 강하게 결합되어 있어, 가중치 반영 시 비가중 비율 대비 차이가 확연히 드러난다
