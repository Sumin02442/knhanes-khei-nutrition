# 12주차 팀 과제: 민감도분석

원시자료(`hn24_all.sas7bdat`)의 실제 식생활평가지수 총점 변수명은 `HEI`이며, 본 분석 및 문서에서 `HE_khei`는 `HEI`와 동일한 변수(`HE_khei = HEI`)를 의미합니다.

## D-1. 민감도분석 계획표

| 구분 | 바꾸는 가정 (단일 가정 변경) | 근거 | 예상 결과 |
| :--- | :--- | :--- | :--- |
| **주 분석 (모형 2)** | 기준 모형: `wt_ntr` 가중치 및 층(`kstrata`)–집락(`psu`) 반영 설계 기반 SE로 총효과(`genertn_rc` → `HEI`, 보정변수: `age`, `sex`, `incm`, `edu`) 추정 | 11주차 회귀분석 모형 2와 동일한 표본(`n = 5,652`) 및 모형으로 결과 재현 확인 | `n = 5,652`, `β = -2.49`, `95% CI = [-3.45, -1.52]` |
