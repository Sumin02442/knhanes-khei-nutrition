> **Table 3 각주**
> 1. **자료 출처 및 연도**: 질병관리청 국민건강영양조사 제9기 2차년도(2024년) 원시자료(`hn24_all.sas7bdat`)를 이용하였으며, 실제 식생활평가지수 총점 변수명 `HEI`와 문서 표기 `HE_khei`는 동일한 변수(`HE_khei = HEI`)임.
> 2. **설계 반영 방법**: 주 분석과 S3은 영양조사 가중치(`wt_ntr`), 분산추정 층(`kstrata`), 조사구/집락(`psu`)을 반영한 설계 기반 추정(`fit_design_wls_domain`)을 적용하였으며, S2는 층(`kstrata`)을 반영하지 않고 가중치(`wt_ntr`)와 집락(`psu`)만 반영한 군집 강건 표준오차(`cov_type='cluster'`) 근사치임. S3은 원자료 행을 삭제하지 않고 연령 기준 도메인 표시변수(`subpop_age65_ge`, `subpop_age65_lt`)로 구분하여 분석함.
> 3. **분석별 변경 사항**: S2는 표준오차 산출 방식만 군집 강건 SE 근사로 바꾸었고 분석 대상(`n = 5,652`)과 공변량(`age`, `sex`, `incm`, `edu`)은 주 분석과 동일함. S3은 연령(65세 이상 `n = 1,791` / 65세 미만 `n = 3,861`) 도메인별로 동일 모형을 적합함.

## D-3. 결과 해석 및 13주차 보고서 핵심 문장

* **결론 일관성 및 가정 민감도**:
  * 주 분석(`β = -2.49`, 95% CI: `[-3.45, -1.52]`, `p < 0.0001`)과 모든 민감도분석에서 1인 가구일수록 식생활평가지수(KHEI) 총점이 낮아지는 **음의 관련성 방향과 통계적 유의성은 일관되게 유지**됨.
  * **SE 산출 가정(S2)**: 집락(`psu`)만 반영한 군집 강건 SE(`SE = 0.47`, 95% CI: `[-3.41, -1.56]`) 근사로 바꾸어도 회귀계수(`β = -2.49`, `Δβ = +0.00`)는 동일하고 신뢰구간 폭만 소폭 좁아지는 수준으로, 주 분석 결론에 영향을 주지 않음.
  * **연령 도메인 가정(S3)**: 결과의 크기와 정밀도는 연령대 구분에 따라 차이를 보임. 65세 미만(`n = 3,861`)에서는 1인 가구의 점수 감소 폭이 **-3.03점**(95% CI: `[-4.23, -1.82]`, `p < 0.0001`, `Δβ = -0.54`)으로 전체 평균보다 크게 나타난 반면, 65세 이상(`n = 1,791`)에서는 **-1.50점**(95% CI: `[-2.92, -0.07]`, `p = 0.0399`, `Δβ = +0.99`)으로 감소 폭이 작고 신뢰구간 상한이 0에 더 가까움. 즉, **연령대(65세 기준) 층화 가정**이 효과 크기 차이를 드러내는 핵심 요인임.
* **13주차 보고서에 쓸 핵심 문장**:
  1. 2024년 국민건강영양조사 성인 표본 분석에서 1인 가구는 다인 가구보다 식생활평가지수(KHEI) 총점이 평균 2.49점 낮았으며(`95% CI: [-3.45, -1.52]`), 이 음의 관련성은 표준오차 산출 방식 변경(`S2`)과 연령 도메인 분할(`S3`)에서도 일관되게 유지되었다.
  2. 층(`kstrata`)을 제외한 군집 강건 표준오차(`S2`) 적용 시에도 회귀계수(`β = -2.49`)와 통계적 유의성이 동일하여, 표준오차 추정 방식의 차이가 전체 결론을 좌우하지 않음을 확인하였다.
  3. 연령 도메인 분석(`S3`)에서는 65세 미만 1인 가구의 식생활 점수 감소 폭(`β = -3.03`)이 65세 이상(`β = -1.50`)보다 더 크게 나타나, 청·중장년층 1인 가구를 중심으로 한 식생활 개선 지원의 필요성을 시사한다.
