# 09 Protocol: 1인 가구 여부와 식생활평가지수의 관련성 연구

## 1. 연구질문
* **연구질문**: 2024년 국민건강영양조사에 참여한 20세 이상 성인에서 1인 가구와 다인 가구의 식생활평가지수 총점에는 차이가 있는가?
* **P (Population / 대상)**: 2024년 국민건강영양조사 참여자 중 만 20세 이상 성인
* **E (Exposure / 노출)**: 1인 가구 (`genertn == 1`)
* **C (Comparator / 비교)**: 다인 가구 (`genertn != 1`)
* **O (Outcome / 결과)**: 식생활평가지수 점수 (`HE_khei`, 연속형)
* **설정 근거**: 횡단면 조사 자료의 특성을 고려하여 인과 추론 대신 두 집단 간의 관련성 및 점수 차이를 평가함.

## 2. 사용 자료 및 가중치
* **사용 자료**: 2024년 국민건강영양조사 (제9기 2차년도 원시자료)[cite: 4]
* **가중치**: 영양조사 가중치 (`wt_ntr`)[cite: 4]
  * **선정 근거 및 논리**: 국민건강영양조사 원시자료 이용지침서의 복합표본 분석 시 가중치 적용 원칙에 따라, 가구조사(`genertn`), 건강설문(공변량), 영양조사(`HE_khei`) 등 서로 다른 조사 부문의 변수를 결합하여 분석할 때는 조사 대상이 가장 제한되어 표본 수가 가장 작은(가장 보수적인) 부문의 가중치를 적용해야 함. 따라서 주된 결과변수인 식생활평가지수가 영양조사 영역에서 산출되므로, 모형의 통계적 대표성과 정확성을 담보하기 위해 영양조사 가중치(`wt_ntr`)를 최종 선택함.
  * **지침서 참고 위치**: 질병관리청, 『국민건강영양조사 제9기(2022-2024) 원시자료 이용지침서』, 제3장 복합표본설계 및 가중치 적용 (부문별 가중치 선택 기준 및 결합 분석 파트)
* **분산추정 변수**: 
  * 집락(PSU): `psu`[cite: 4]
  * 분층(Strata): `kstrata`[cite: 4] 이것도

## 4. 분석 대상 선정 계획

1. 2024년 국민건강영양조사 전체 참여자 ($N = 6,997$)
2. 만 20세 이상 성인 (연령 필터링 적용 대상)
3. 영양조사 가중치(`wt_ntr`) 유효 대상자 ($N = 6,805$)
4. 10주차 Table 1 분석을 위해 공변량 결측치는 일괄 제외하지 않고 별도 표시하며, 주요 변수 분석에 필요한 대상자 규모를 확정함.
